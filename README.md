# Ryubing: A Personal Fork

> **Disclaimer:** This is **not** an official Ryubing build and is not affiliated with or endorsed by the upstream Ryubing project. It is a personal fork where I work on changes in areas that interest me, for my own use.

## Why this fork exists

I started working on some fixes and improvements with the help of AI tooling, and only afterward found that the upstream project does not permit LLM-assisted contributions. That's a reasonable policy for them to set on their own project. I still wanted to make my changes and to make them available to anyone who wants them, including the upstream maintainers themselves should they ever change their stance.

So rather than let the work sit unused, it lives here.

## Intent

To be clear about what this is and isn't:

- I intend to keep this **reasonably up to date** with upstream.
- I have **zero intention** of duplicating upstream's work, competing with it, or fragmenting the project. I don't have the time or the expertise for that, and I wouldn't want to.
- This is a personal copy of a project I like using, made public on the off chance the changes are useful to someone else.

## Builds

I do **not** provide builds. If you want a build, build it yourself by following the upstream project's build instructions.
